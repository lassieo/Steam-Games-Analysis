# Steam Game Success Predictor — Streamlit App

Interactive web app with three tabs:

1. **Predictor** — enter game attributes, get a success probability with live SHAP explanation
2. **Chatbot** — ask natural language questions about the dataset (powered by Groq's free Llama 3.1 API)
3. **Dashboard** — explore EDA findings and model results interactively

## Architecture

```
streamlit_app/
├── app.py                    # Main entry point, tab structure
├── predictor.py              # Tab 1 — prediction form + SHAP
├── chatbot.py                # Tab 2 — structured RAG with Groq
├── dashboard.py              # Tab 3 — interactive charts
├── utils.py                  # Shared data/model loading
├── requirements.txt          # Python dependencies
├── models/
│   ├── xgb_tuned.pkl         # Trained model (generated by export_model.py)
│   ├── feature_columns.json  # Feature order for predictions
│   └── feature_stats.json    # Per-feature ranges for the UI
├── data/
│   └── steam_features_engineered.csv  # Engineered dataset
└── .streamlit/
    └── secrets.toml          # Groq API key (not committed)
```

## Local setup

From the repository root:

```bash
# 1. Install dependencies
pip install -r streamlit_app/requirements.txt

# 2. Generate the model pickle (one-time, takes ~2 minutes)
python export_model.py

# 3. Copy the engineered dataset to the app folder
mkdir -p streamlit_app/data
cp data/output/steam_features_engineered.csv streamlit_app/data/

# 4. Add your Groq API key
mkdir -p streamlit_app/.streamlit
cp streamlit_app/.streamlit/secrets.toml.example streamlit_app/.streamlit/secrets.toml
# Edit streamlit_app/.streamlit/secrets.toml and paste your key

# 5. Run the app
streamlit run streamlit_app/app.py
```

The app opens at `http://localhost:8501`.

## Getting a Groq API key

1. Go to [console.groq.com](https://console.groq.com)
2. Sign up (no credit card required)
3. Create an API key — it starts with `gsk_...`
4. Paste it into `streamlit_app/.streamlit/secrets.toml`

The free tier gives 14,400 requests per day and 500,000 tokens per day on Llama 3.1 8B Instant, which is more than enough for a class demo.

## Deploying to Streamlit Community Cloud

1. Make sure `streamlit_app/data/steam_features_engineered.csv` and `streamlit_app/models/*.pkl` are committed to the repo (the `.gitignore` already allows these)
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub
3. Click "New app" and select the `Steam-Games-Analysis` repo
4. Set main file path to `streamlit_app/app.py`
5. Under "Advanced settings", add your secrets:
   ```toml
   GROQ_API_KEY = "gsk_your_key_here"
   ```
6. Click Deploy

The app will be live at `https://<your-app-name>.streamlit.app` within a few minutes.

## Important files to commit

These files MUST be committed for the deployed app to work:

- `streamlit_app/app.py` and all `.py` files
- `streamlit_app/requirements.txt`
- `streamlit_app/models/xgb_tuned.pkl` (~15 MB)
- `streamlit_app/models/feature_columns.json`
- `streamlit_app/models/feature_stats.json`
- `streamlit_app/data/steam_features_engineered.csv` (~50 MB)

These files MUST NOT be committed:

- `streamlit_app/.streamlit/secrets.toml` (contains your API key)

Make sure your repo `.gitignore` contains:
```
streamlit_app/.streamlit/secrets.toml
```

## Troubleshooting

**"Model file not found"** — run `python export_model.py` from the repo root first.

**"Data file not found"** — copy `data/output/steam_features_engineered.csv` to `streamlit_app/data/`.

**Chatbot says "needs a Groq API key"** — add your key to `streamlit_app/.streamlit/secrets.toml`.

**Chatbot hits rate limits** — the free tier allows 14,400 requests per day. Wait a minute and try again. The app uses `llama-3.1-8b-instant` which has the highest request allowance on the free tier.

**Streamlit Cloud deployment fails with "file too large"** — your engineered CSV might be too big. Try compressing columns or subsampling.
